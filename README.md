# Safari iOS untuk Android (iOS 18 + iOS 27)
1. Upload semua isi folder ini ke repo GitHub (branch main).
2. Tab Actions -> Build APK -> tunggu selesai.
3. Download artifact "Safari-iOS-debug", ekstrak, install app-debug.apk.
Ganti tampilan: tombol ... (toolbar) -> Tampilan Safari -> iOS 18 / iOS 27.
